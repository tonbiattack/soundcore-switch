# クイック設定タイルとシステムトレイ

対応 Issue: [#15](https://github.com/tonbiattack/soundcore-switch/issues/15) / [#16](https://github.com/tonbiattack/soundcore-switch/issues/16)

最終更新: 2026-11-18

## 1. Android: クイック設定タイル

通知シェードから素早く接続先を切り替える。

### 使い方

1. 通知シェードを開き、編集（鉛筆アイコン）をタップ
2. 「Soundcore」タイルをドラッグして追加
3. タイルをタップするとアプリの画面が開く

### 設計判断: タイルは画面を開くだけ

タイル上で接続先を直接選ぶのではなく、**アプリの画面を開く**方式にした。理由:

- 接続先の選択には一覧の取得（RFCOMM 通信）が必要で、タイルの狭い領域では表現しきれない
- 誤操作を防ぐには、対象を確認してから切り替える必要がある
- 常駐サービスを持たずに済む（仕様書「バックグラウンド常駐をMVP必須としない」に沿う）

### タイルに接続先の状態を出さない理由

接続先の状態は**通信しないと分からない**。タイルに古い状態を出すと、
「最新の情報」と誤認させる恐れがある。そのためタイルは
「タップで開く」ことだけを伝え、状態は表示しない。

### 実装

`app/src/main/java/com/tonbiattack/soundcoreswitch/tile/SwitchTileService.kt`

- `TileService` を継承。`onClick` でアプリを開く。
- ロック画面からは開けないため、その場合はタイルの状態だけ更新して戻る。
- `startActivityAndCollapse` のシグネチャは API 34 で変わったため、バージョンで分岐する。

## 2. Windows: システムトレイ

Windows 版を常駐させ、画面を開かずに接続先を操作する。

### 使い方

1. アプリを起動するとタスクトレイにアイコンが出る
2. アイコンを左クリック、または右クリックでメニューを開く
3. 「接続中」「切り替え先」から対象を選ぶ

### メニューの構成

```
接続中
  OPPO Reno13 A
  DELLTOWER
─────────────
切り替え先
  DESKTOP-ILQVMVD
  Redmi Pad SE 8.7
─────────────
更新
画面を開く
─────────────
終了
```

- 接続中と切り替え先を分けて表示する（どれが今つながっているか一目で分かる）
- 切り替えできない状態（未対応機種・Bluetooth オフ等）ではメニュー項目が無効になる
- 「終了」はトレイメニューからのみ。ウィンドウの×はトレイに格納する

### 不要なポーリングをしない

常駐しても**定期的な Bluetooth 通信は行わない**。状態は画面と同じ ViewModel を
共有しているため、画面を開いたとき・手動更新したときだけ取得する。

### 切り替えの安全性

トレイからの切り替えも、画面と同じ `SwitchTargetUseCase` を通す。
そのため「要求を送れたこと」と「切り替えが成立したこと」を区別し、
成功の確定は状態の再取得で行う。トレイから操作しても誤った成功表示はしない。

### 実装

`desktop/src/main/kotlin/com/tonbiattack/soundcoreswitch/desktop/tray/AppTray.kt`

- Compose Desktop の `Tray` を使う。
- アイコンが読めない場合は単色の四角で代替する（起動を止めない）。

## 3. 自動起動

**初期状態では無効。** 必要なら Windows のスタートアップに
ショートカットを置く（ユーザーが任意で設定する）。
