## 2. 実装の由来

本アプリのプロトコル処理は、実機の通信を観測して独自に解読したものである。

| 確認項目 | 結果 |
|---|---|
| 純正アプリの APK を取り出して逆コンパイルしたか | していない |
| 純正アプリのコード・リソースを転載したか | していない |
| ファームウェアを抽出・解析したか | していない |
| 認証・ライセンス保護を回避したか | していない（ペアリング済み端末との通常の RFCOMM 通信のみ） |
| 公式ロゴ・画像を使っているか | 使っていない（アイコンは自前生成） |

**方法**: ペアリング済みのイヤホンに対し、Android の `BluetoothSocket` で
ベンダー UUID の RFCOMM サービスへ接続し、送受信バイト列を観測した。
得られたバイト列からパケット形式を推定し、独自に実装した。

## 3. 依存ライブラリのライセンス

| ライブラリ | ライセンス | 互換性 |
|---|---|---|
| Kotlin / kotlinx.coroutines | Apache-2.0 | 問題なし |
| AndroidX（Compose, Lifecycle, DataStore） | Apache-2.0 | 問題なし |
| Compose Multiplatform | Apache-2.0 | 問題なし |
| JNA / JNA Platform | Apache-2.0 / LGPL-2.1（デュアル） | Apache-2.0 を選択 |
| JUnit 4 | EPL-1.0 | テストのみ。配布物に含まれない |

**GPL のコードは含まれていない。** BudsLink（GPL-3.0）とは独立に実装しており、
コードの流用・参照は行っていない。プロトコルの事実（コマンド番号など）は
アイデアであり、著作権の保護対象ではないと解釈している。

> **未確認**: この解釈が日本の著作権法上妥当かは専門家の確認が必要。

## 4. 商標の扱い

「Soundcore」「Anker」は Anker Innovations の商標である。

| 方針 | 内容 |
|---|---|
| 製品名の使用 | 「Soundcore イヤホンに対応」という**事実の記述**に限定する |
| ロゴ・画像 | 一切使用しない |
| 誤認の防止 | 「非公式」「Anker とは無関係」を README 冒頭とアプリ内に明記する |
| アプリ名 | 商標を含まない独自名称にする（§5） |

## 5. 名称の変更

現在の表示名「Soundcore Switch」は商標を含むため、公開時に変更する。

| 候補 | 確認事項 |
|---|---|
| BudsSwitch | 「Buds」は一般名詞。既存アプリとの衝突を要確認 |
| Multipoint Switcher | 一般名詞のみ。識別性は低い |
| EarSwitch | 一般名詞のみ |

**リポジトリ名と applicationId は変更しない。** 変更すると既存インストールの
更新ができなくなる（`com.tonbiattack.soundcoreswitch` は維持）。

> **未確認**: 各候補の商標登録・既存アプリとの衝突は J-PlatPat 等で確認が必要。
