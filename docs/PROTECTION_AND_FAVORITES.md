# 接続先の保護とお気に入り

対応 Issue: [#13](https://github.com/tonbiattack/soundcore-switch/issues/13) / [#17](https://github.com/tonbiattack/soundcore-switch/issues/17)

最終更新: 2026-11-18

## 1. なぜ保護が必要か

接続上限（2台）に達しているとき、3台目へ切り替えるには既存の接続先を1台切断する必要がある。
このとき**誤って必要な端末を切ると損失が大きい**（操作元の PC を切れば通信が途切れ、
作業中の端末を切れば相手の接続が落ちる）。

そのため、次の原則で切断対象を決める。

1. **同一性は MAC アドレスで判定する。** 表示名は端末側で変更でき、同名の端末もあり得る。
2. **保護された端末は決して切らない。**
3. **操作元の端末は切らない。** 切ると通信が途切れて切り替えが成立しない。
4. **切断してよいと確信できない場合は、切り替えを中止する。**
   切り替えできないことより、必要な端末を切ることのほうが損失が大きい。

## 2. 保護の使い方

接続先の行にある 🔓 / 🔒 ボタンで切り替える。保護した端末には「保護」バッジが付く。

保護された端末は、接続上限に達しても自動で切断されない。
すべての接続先が保護されている場合、切り替えは中止され、理由が表示される。

## 3. 中止される条件

| 状況 | 表示される理由 |
|---|---|
| 接続中の端末がすべて保護されている | 「接続中の端末がすべて保護されています」 |
| 操作元の端末しか接続されていない | 「この端末しか接続されていません」 |
| どの接続先が操作元か特定できない | 「どの接続先がこの端末か特定できませんでした」 |
| 接続中の端末が見つからない | 「接続中の端末が見つかりませんでした」 |

いずれも**切断コマンドを送らずに中止する**。誤切断を避けるため。

## 4. 操作元の特定方法

プロトコルは「どの接続先が操作元か」を返さないため、プラットフォームごとに取得する。

| プラットフォーム | 取得方法 | 取得できない場合 |
|---|---|---|
| Android | `BluetoothAdapter.getAddress()` をリフレクションで取得 | 中止（安全側） |
| Windows | レジストリの `BluetoothAddress` を読む | 中止（安全側） |

Android 6.0 以降、`getAddress()` は `02:00:00:00:00:00` を返すため使えない。
リフレクションで取得し、取得できなければ null を返して安全側に倒す。

## 5. お気に入り

接続先の行にある ☆ / ★ ボタンで切り替える。お気に入りは一覧の先頭に表示される。

- **ID（MAC）で保存する。** 表示名が変わっても設定は維持される。
- お気に入り同士・通常同士は元の順序を保つ（毎回順序が変わると探しにくい）。
- 端末が登録から外れても設定は残る（再度登録されれば復元される）。

## 6. 実装

| クラス | 役割 |
|---|---|
| `ProtectionSettings` | 保護設定の値オブジェクト |
| `SelectDisconnectCandidateUseCase` | 切断候補の選択（誤切断の防止） |
| `OrderTargetsUseCase` | お気に入りを先頭にした並べ替え |
| `ProtectionCache` | 保護設定のメモリキャッシュ（同期的に参照するため） |

`SoundcoreMultipointAdapter` は切断候補の選択を
`SelectDisconnectCandidateUseCase` に委譲する。アダプタ自身は判定しない。

## 7. テスト

| テスト | 検証内容 |
|---|---|
| `SelectDisconnectCandidateUseCaseTest` | 保護・操作元の除外、中止条件、同名端末の区別 |
| `OrderTargetsUseCaseTest` | お気に入りの優先表示、順序の安定性 |
| `SoundcoreAdapterDeviceRegressionTest` | 保護時に切断コマンドを送らないこと |

## 8. 未確認点

- 実機での保護設定の永続化（再起動後の復元）
- Android 実機での操作元 MAC 取得（リフレクションが通るか）
- Windows での操作元 MAC 取得（レジストリのパスが環境により異なる可能性）
