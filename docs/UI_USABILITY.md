# 画面の使い勝手

最終更新: 2026-11-20

## 1. イヤホンの選択

複数の Soundcore イヤホンをペアリングしている場合、画面上部に**選択中の1台だけ**を表示する。
右端の ▼ をタップすると、他のイヤホンがドロップダウンで開く。

### どれが自動で選ばれるか

起動時・画面復帰時に、次の優先順位で選ぶ。

1. **接続中のイヤホン**（今つながっているもの）
2. 現在の選択（接続中でなくても、ユーザーが選んだものは維持する）
3. 前回選択（仕様書 F-07）
4. 先頭

**接続中を最優先にする理由**: ユーザーが最も操作したいのは今つながっているイヤホン。
複数ペアリングしていると、前回選んだ別の機種が選ばれたままで
「なぜか切り替えられない」状態になっていた。

接続状態が `UNKNOWN`（取得不可）の場合は「接続中」として扱わない。
取得できなかっただけで、つながっているとは限らないため。

接続中が複数ある場合（マルチポイントの上限は2台）は、検出順の先頭を使う。

### なぜドロップダウンなのか

以前は「他のイヤホンを表示」を押すと一覧が下に展開する方式だった。
この方式には次の問題があった。

- 展開すると接続先一覧が押し下げられ、**接続先を選ぶには毎回折りたたむ必要があった**
- 画面が上下に分かれて見え、どちらを操作すべきか分かりにくかった

ドロップダウンは**重ねて表示**するため、下の接続先一覧が動かない。
イヤホンを選んだ後も、接続先が同じ位置にあり続ける。

### 1台だけのとき

イヤホンが1台しか検出されない場合は、選択の必要が無いため ▼ を出さない。
画面の縦を接続先一覧に使える。

## 2. 失敗したときの Bluetooth 状態

切り替えに失敗したとき、バナーに **Bluetooth の現在の状態**を併記する。

```
応答がありませんでした
イヤホンからの応答を待ちきれませんでした。イヤホンを再接続してから、もう一度お試しください。
Bluetooth: オン
```

### なぜ必要か

「切り替えられなかった」だけでは、原因が分からない。

| 状態 | 疑うべき原因 |
|---|---|
| Bluetooth: オフ | 端末の設定でオンにする |
| Bluetooth: 権限がありません | 権限を許可する |
| Bluetooth: オン | イヤホン側の問題（接続・電波・純正アプリの競合） |

Bluetooth がオンなのに失敗しているなら、イヤホン側を疑えばよい。
この切り分けができるだけで、利用者の次の行動が変わる。

### 表示する状態

| 状態 | 表示 |
|---|---|
| オン | `Bluetooth: オン`（通常色） |
| オフ | `Bluetooth: オフ`（エラー色） |
| 権限なし | `Bluetooth: 権限がありません`（エラー色） |
| 非対応 | `Bluetooth: この端末は非対応`（エラー色） |
| 判定不能 | `Bluetooth: 状態を確認できません`（エラー色） |

成功時は表示しない。成功したときに状態を見せても情報が増えないため。

## 3. 実機で確認したこと（2026-11-20 / OPPO CPH2699）

| 項目 | 結果 |
|---|---|
| イヤホン選択が1行にまとまる | ✅ |
| ▼ でドロップダウンが開く | ✅ |
| ドロップダウン表示中も接続先一覧が動かない | ✅ |
| イヤホンを選ぶと接続先が切り替わる | ✅ Space A40 に切り替え |
| 失敗時に Bluetooth 状態が出る | ✅ 「Bluetooth: オン」を確認 |
